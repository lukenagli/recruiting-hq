The problem

Banking recruiting is a networking sprint, and the admin buries you

  • A first-year talks to 25 to 40 bankers and 2Ys across 10+ banks in one fall
  • Each chat: log it, send a club-format thank-you within a day, remember who referred you
  • Then technical prep, a deal pitch, and a cover letter per bank
  • Today: an Excel sheet, notes from memory, a 3,116-row question bank
15–20 minof admin per coffee chat (my estimate)
1–2 hrsper cover letter, rewritten for every bank

Roughly 15 to 30 hours a student per season, during the busiest months of the MBA.

How the agents work

Code orchestrates; each agent gets only what it needs

All agents run on gpt-6-luna (course key via Portkey; students can bring their own key). Typed outputs, validated tools.

Cost to run · measured from 93 logged runs

About a tenth of a cent per run

$0.0012file a chat + draft the thank-you (real run)
~$0.13per active student per month
~$20/mo100 students, incl. $7 hosting
~$1,450/mo10,000 students, incl. bigger servers
  • Prompt caching: 76% of the assistant's input cached → 54% cheaper per run
  • The model writes only what code can't: 2 details of a thank-you, never the math
  • Trade-off: the cheap model needs retries (3.3 requests per assistant run; every letter came back with at least one flag to fix)

gpt-6-luna: $0.10/M input · $0.01/M cached · $0.50/M output

Safety

The injected email got filed, and nothing in it ran

  • No delete or send tools, so an injection has nothing dangerous to call. Contacts: 6 before, 6 after
  • Every row scoped to the signed-in user
  • Off-topic and stock tips refused
  • Daily budget 400k tokens/account → HTTP 429 (tested)
  • Run caps stop loops (tested) · Undo restores (tested)
  • Nothing is ever sent for you: drafts only
